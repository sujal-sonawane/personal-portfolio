# Personal Portfolio Website

## Overview

A responsive personal portfolio website developed using HTML5, CSS3, and JavaScript. The project presents personal information, education, technical skills, projects, and contact details in a structured single-page portfolio.

The project also includes basic JavaScript functionality such as dark mode, automatic copyright year generation, and client-side contact form validation.

---

## Features

- Personal introduction and profile section
- Navigation bar with section links
- About section
- Education details and academic results
- Technical skills categorized into frontend, backend, database, and tools
- Projects showcase
- Contact form
- Basic contact form validation
- Dark mode and light mode toggle
- Automatic current year in the footer
- Smooth scrolling navigation
- Responsive layout for smaller screens
- GitHub and LinkedIn profile links

## How It Works

The portfolio is built as a single-page website.

The HTML file contains the main structure and sections of the portfolio. The CSS file controls the layout, styling, responsive behavior, and dark-mode appearance.

JavaScript adds basic interactivity:

1. The current year is automatically inserted into the footer.
2. The Dark Mode button toggles the `dark-mode` class on the `<body>`.
3. The button text changes between `Dark Mode` and `Light Mode`.
4. The contact form prevents the default submission.
5. JavaScript checks whether the name, email, and message fields are filled.
6. A validation message is displayed to the user.
7. The form is reset after successful validation.

## How to Run

### Method 1: Open Directly

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The portfolio will open in your default web browser.

### Method 2: Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server** if the Live Server extension is installed.
